# Projective-space module and API map

This hand-maintained map describes the **current** 43 Lean files: 28 mathematical
leaves plus the aggregate root, nine test clients, two diagnostic modules and
three complete private reader examples. The 28 leaves and root use native
`module` headers and deliberate public imports. The table lists actual direct
imports and principal interfaces, not a generated declaration census or
source-coverage inventory. Test clients and diagnostics are not library API.
See the [reader guide](../README.md) and the six standalone mathematical
guides for the hypotheses and usage of the principal results.

The three complete modules in [`examples/`](../examples/) independently
ordinary-import selected production leaves; they add private usage checks, not
public theorems. Use `import ProjectiveSpace` for the aggregate API or import an
individual leaf, with `open scoped ProjectiveSpace` for the polynomial grading.
The four Lake targets are `ProjectiveSpace` (root and 28 leaves),
`ProjectiveSpaceTest` (nine clients), `ProjectiveSpaceAxiomTests` (two selected-
name diagnostics) and `ProjectiveSpaceReaderExamples` (three examples).
`lean-toolchain`, `lakefile.toml` and `lake-manifest.json` pin Lean
`v4.34.0-rc2` and the resolved 13-package graph, including official Graded
Rings and Scheme Properties. Previous full-graph reviews and standard-axiom
audits apply to their exact inputs; this map does not independently certify
changed header bytes, publication or source correspondence.
